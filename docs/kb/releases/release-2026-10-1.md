## Highlights

Sift 2026.10.1 is the first release with a version number. It sets the baseline: later release notes list what changed since.

- Nightly screening of about 500 ASX companies: valuation (DCF, or DDM for banks, insurers and REITs), four value tests, markers, a 30-check score wheel and a suggested action with its reason.
- ETFs and LICs collected and shown apart from shares, with Sift's own returns, ranks and reference funds.
- Portfolios with parcel-level CGT records, watchlists with triggers, Coattail (fund manager moves), and a track record that scores Sift's calls.
- Search across everything, learning from use, with meaning-based search ready but off.
- Multi-user foundations: accounts and owners (Phase 1), each person's nightly results (Phase 2), Profile, Preferences, a Users tab and impersonation.
- This developer knowledge base, with generated references, an improvement register, decision records, runbooks and review dates.

## Upgrade steps

From any earlier copy: `git pull`, then restart Sift (`start_sift.bat`). The database schema updates itself on start and before the nightly run. No manual steps.
